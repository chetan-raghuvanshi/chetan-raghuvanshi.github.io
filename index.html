I work on the layer between AI coding agents and the machines they run on. At failproof ai that means intercepting an agent's tool calls at runtime and deciding, in milliseconds, whether to block, sanitize, or redirect them, and then building the collectors, evaluators and cloud protocol that make those decisions measurable and deployable across every installed machine.

Outside work I build agent systems: self-hosted multi-agent dev platforms, agents that learn recovery skills under injected faults, and tooling for navigating agent sessions. I'm also finishing my undergrad in Computer Science at Sir M. Visvesvaraya Institute of Technology, Bengaluru.

Projects

  • Monk · TypeScript An agent that learns to recover from failure. A seeded chaos proxy injects 16 API and device faults into every MCP tool; recoveries are written as SKILL.md files and kept only if they win an A/B rerun under the same faults. Solved 12/13 real GitHub tasks under moderate chaos; under heavy chaos, faults recovered rose from 18% to 48% after learning.
  • kiln · Rust Self-hosted, multi-tenant agentic dev platform. A daemon schedules tasks through Planner → Builder → QA → Reviewer in isolated Docker containers and ends each in a PR with QA evidence. Shared "company brain" on LanceDB + DataFusion; TUI and Leptos/Tauri clients for desktop and Android; MCP endpoint with OAuth 2.1.
  • braid · Go Turns forked Claude Code sessions into a navigable, queryable graph: tree, cd, read, headless ask against any session (hash-verified, never mutates it), pull-based merges and an append-only shared ledger. Local-first, single static binary.
  • SwarmHands · Python · 1st place, OpenSwarm Hackathon A personal agent mesh driven from Telegram (text or locally transcribed voice). A tool-less coordinator fans out parallel specialists: GitHub via per-agent git worktrees, the phone via adb (calls, WhatsApp, relaying SMS OTPs to the laptop), and vision-guided web tasks.
  • PullSmith · Python · team project · 2nd place, Anvil Hackathon HMAC-verified GitHub webhooks trigger a 7-agent PR pipeline: typed plan, multi-hop research, parallel review and security scans, generated tests in a sandbox with up to 3 self-healing attempts, then a rule-checked merge / reject / file-bug decision. Live progress over SSE. Built in 24 hours.
  • Munim · Python A self-configuring operating system for small businesses over WhatsApp / Telegram. ~10 agents over shared durable state: Hindi/Hinglish voice intake, UPI-screenshot verification, bounded price negotiation, and SELECT-only NL-to-SQL on whitelisted tables. Phrasings seen once compile into local skills, so repeats cost zero API calls.
