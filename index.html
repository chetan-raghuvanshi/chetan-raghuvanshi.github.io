I work on the layer between AI coding agents and the machines they run on. At failproof ai that means intercepting an agent's tool calls at runtime and deciding, in milliseconds, whether to block, sanitize, or redirect them, and then building the collectors, evaluators and cloud protocol that make those decisions measurable and deployable across every installed machine.

Outside work I build agent systems: self-hosted multi-agent dev platforms, agents that learn recovery skills under injected faults, and tooling for navigating agent sessions. I'm also finishing my undergrad in Computer Science at Sir M. Visvesvaraya Institute of Technology, Bengaluru.

At failproof ai

Founding Engineer, Jul 2026 – present. TypeScript, Rust, ClickHouse, PostgreSQL, Kubernetes.

  • Two-tier semantic policy evaluation. Regex policies stay as hard blocks; a second stage sends 15 judgment-heavy policies to a model-based reviewer, opt-in locally (bring your own key) or via a rate-limited, fail-open Cloud endpoint. Replayed over 16.8k real tool calls: block rate fell from 33.3% to 7.4% while attacks caught rose from 77 to 123.
  • Agent harness integrations. Hooked the tool-call lifecycle of Hermes, OpenClaw, Goose, Devin CLI, Factory Droid and Antigravity into a 39-policy block / sanitize / instruct engine that now covers 12 harnesses. Verified against live CLIs rather than docs, which caught schema and timeout-unit bugs the published specs missed.
  • Transcript collector, in Rust. Session ingestion for 12 agent CLIs inside the daemon: JSONL tailers, a SQLite poller with message-id dedup (removing 2–4× duplicate events), and a backward-compatible epoch hook for sources with no timestamps.
  • Daemon-to-cloud protocol. Signed policy bundles, cursor-based spool-and-ack delivery for at-least-once event shipping, and version-safe rollout; policy packs pinned to commit SHAs.
  • Evaluation infrastructure. Policy backtesting that replays historical tool calls out of ClickHouse against candidate policies before rollout, and automated eval generation on an isolated Kubernetes eval pod that pushes results back to the server.
  • Integration canary. A daily CI canary that runs harmless probes against every supported agent CLI, version-gates reruns, and reports pass / fail / inconclusive to Slack.
  • Internal agents and alerting. A fleet of autonomous Rust/Codex agents in locked-down, budget-capped containers: PR review that boots each PR's full stack and drives it with Playwright, issue-to-PR automation, canary failure diagnosis, and a production-alert agent that digests errors and policy denials into Slack twice a day. The fleet runs under failproof ai's own tracing.

Projects

  • Monk · TypeScript An agent that learns to recover from failure. A seeded chaos proxy injects 16 API and device faults into every MCP tool; recoveries are written as SKILL.md files and kept only if they win an A/B rerun under the same faults. Solved 12/13 real GitHub tasks under moderate chaos; under heavy chaos, faults recovered rose from 18% to 48% after learning.
  • kiln · Rust Self-hosted, multi-tenant agentic dev platform. A daemon schedules tasks through Planner → Builder → QA → Reviewer in isolated Docker containers and ends each in a PR with QA evidence. Shared "company brain" on LanceDB + DataFusion; TUI and Leptos/Tauri clients for desktop and Android; MCP endpoint with OAuth 2.1.
  • braid · Go Turns forked Claude Code sessions into a navigable, queryable graph: tree, cd, read, headless ask against any session (hash-verified, never mutates it), pull-based merges and an append-only shared ledger. Local-first, single static binary.

A tool-less coordinator fans out parallel specialists: GitHub via per-agent git worktrees, the phone via adb (calls, WhatsApp, relaying SMS OTPs to the laptop), and vision-guided web tasks.

Live progress over SSE. Built in 24 hours.
